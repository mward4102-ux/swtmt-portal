# PlastiBioFuel Funnel Tracker

Target: **50 outreaches → 10 conversations → 2 to 3 pilots or letters of intent.**

Every run updates this file. It is the only place the counts live, and a count here means
one thing only, per the definitions below. Read it after `FUNDING_REGISTRY.md` and
`Outreach/OUTREACH_QUEUE.md`.

## Stage definitions

| Stage | Counts when | Does not count |
|---|---|---|
| **Outreach sent** | A written approach left the building, to a named office, person, or firm. An application submitted to a program counts here too. | Drafted, staged, or queued. A draft in Gmail is not a send. |
| **Reply received** | Any human response, however brief. | Autoresponders, "we received your application" receipts. |
| **Conversation held** | A call, meeting, or substantive written exchange. | A one-line "not a fit" reply. |
| **Pilot or LOI** | A written expression of intent to test, buy, host, fund, or collaborate. | Verbal interest. **ARG Petro is discussions and does not count until something is signed.** |

## Rules

1. **Sent means sent.** Never advance a stage on a draft.
2. **One outreach minimum per run**, more when a batch is warranted. The 50 target does not
   survive one per run: that is a year of runs.
3. **Every count in this file traces to a row** in `Outreach/OUTREACH_QUEUE.md` or to a dated
   submission in a run directory. No aggregate number is written that cannot be pointed at.
4. **A reply naming a person creates a new queue entry.** Referrals are how 50 outreaches turn
   into 10 conversations rather than 50 silences.
5. **Report the funnel in every run summary**, even when nothing moved, and say plainly which
   stage is the constraint.
