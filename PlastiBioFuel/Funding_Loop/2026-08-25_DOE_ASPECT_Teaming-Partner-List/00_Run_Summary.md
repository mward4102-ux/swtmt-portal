A teaming-partner package for **ASPECT**, Accelerating Scale-up and Pre-piloting of
Emerging Chemical Technologies. DOE's Office of Critical Minerals and Energy Innovation
has noticed, on behalf of the Alternative Fuels and Feedstocks Office, that it may issue a
NOFO seeking research, development, and scale-up of technologies that make chemicals from
alternative and waste feedstocks, including foundational molecules and their derivatives.

That is the company's sentence, written by DOE. Post-consumer PET is a waste feedstock and
terephthalic acid is a foundational molecule, and terephthalic acid is the product the UNT
report actually measures. The NOI carries no deadline and no application, but the teaming
list attached to it is open now, and it is how applicants find each other before a NOFO

## Tooling note for future runs

SAM.gov and Grants.gov are reachable from this session, and the way in matters. The
container's HTTPS egress proxy returns 403 for both hosts, and the WebFetch tool returns
EGRESS_BLOCKED for them and for sbir.gov, epa.gov, energy.gov, and connectwerx.org. The
Scrapling connector reaches all of them. Every issuing-agency page cited in this run was
fetched that way.

Two working details worth keeping. SAM.gov's search JSON comes back with unescaped
newlines and quotation marks inside description fields, so a strict JSON parser fails on
it and the fields have to be pulled out tolerantly. Grants.gov answers at
simpler.grants.gov with the query in the URL; the older REST endpoints return 405 or
demand an authentication token.
